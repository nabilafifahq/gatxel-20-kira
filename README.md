# Kira

Website belajar harian Math, English, dan Science untuk anak SD kelas 1 sampai 6 (Cambridge Primary), dengan simulasi lomba nasional dan internasional, konsol tutor, dan halaman orang tua. Berjalan di server rumah (Windows 11, Docker Desktop) dan dibuka lewat Tailscale. Aplikasi tablet Android tersedia sebagai APK.

Standar: GTX-ENG-001 v1.7.
